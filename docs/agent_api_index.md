# SimpleCADAPI Agent API Index

This compact index is intended for injection into an LLM system prompt. Each entry summarizes one non-README Markdown document under `docs/api`, `docs/architecture`, `docs/core`, or `docs/stdlib`; consult the source document when full examples or extended rationale are required.

## API
- `api/Assembly.md` — `Assembly(assembly_id: str, name: Optional[str] = None, components: Tuple[Component, ...] = (), connectors: Tuple[Connector, ...] = (), constraints: Tuple[Constraint, ...] = (), grounded_component_ids: Tuple[str, ...] = ())` represents a product structure containing placed `Part` or subassembly components.
- `api/BSplineFitResult.md` — `BSplineFitResult(degree: int, control_points: Tuple[PointTuple, ...], knots: Tuple[float, ...], sample_parameters: Tuple[float, ...], max_error: float, rms_error: float, tolerance: float, fairing: float, iterations: int, converged: bool)` stores a complete normalized fitted cubic B-spline definition suitable for the exact B-spline edge and wire APIs.
- `api/Component.md` — `Component(component_id: str, item: AssemblyItem, placement: Placement, name: Optional[str] = None)` represents an assembly-local instance of a `Part` or subassembly.
- `api/Connector.md` — `Connector(connector_id: str, geometry_ref: Optional[GeometryRef] = None, name: Optional[str] = None, anchor: Optional[ConnectorAnchor] = None)` defines a semantic datum frame anchored by selected BREP geometry, an explicit placement, or a forwarded component connector.
- `api/ConnectorAnchor.md` — `ConnectorAnchor(anchor_kind: str, geometry_ref: Optional[GeometryRef] = None, placement: Optional[Placement] = None, source_component_id: Optional[str] = None, source_connector_id: Optional[str] = None, offset: Optional[Placement] = None)` serializes a connector datum source whose `anchor_kind` is `geometry`, `placement`, or `forwarded`.
- `api/ConnectorRef.md` — `ConnectorRef(component_id: str, connector_id: str)` references a connector through a component instance.
- `api/Const.md` — `Const(value: float, expr_id: str = field(default_factory=lambda : _make_expr_id('const')))` is an immutable constant node in the v2 expression graph.
- `api/Constraint.md` — `Constraint(constraint_id: str, constraint_kind: ConstraintKind, connector_a: ConnectorRef, connector_b: ConnectorRef, drive_distance: Optional[float] = None, distance_limit: Optional[ScalarLimit] = None, drive_angle_degrees: Optional[float] = None, angle_limit: Optional[ScalarLimit] = None, pitch_radius_a: Optional[float] = None, pitch_radius_b: Optional[float] = None, pulley_radius_a: Optional[float] = None, pulley_radius_b: Optional[float] = None, pitch_radius: Optional[float] = None, phase_offset: Optional[float] = None, name: Optional[str] = None)` represents a connector-to-connector assembly constraint.
- `api/ConstraintReport.md` — `ConstraintReport(solved: bool, grounded_component_ids: Tuple[str, ...], solved_component_ids: Tuple[str, ...], unsolved_component_ids: Tuple[str, ...], residuals: Tuple[ConstraintResidual, ...])` reports assembly constraint inspection results.
- `api/ConstraintResidual.md` — `ConstraintResidual(constraint_id: str, translation_error: float, angular_error_degrees: float, within_tolerance: bool)` records the residual for one assembly constraint.
- `api/Expr.md` — `Expr(op: str, args: Tuple[ScalarExpr, ...], expr_id: str = field(default_factory=lambda : _make_expr_id('expr')))` is a derived scalar expression node built from one or more operands.
- `api/ExpressionGraph.md` — `ExpressionGraph()` is a lightweight registry of expression DAG nodes.
- `api/FreeCADScriptTranslator.md` — `FreeCADScriptTranslator(document_name: str = 'SimpleCADModel')` compiles canonical low-level graph IR into a Part-workbench-style FreeCAD Python script while preserving node metadata, lineage, expression graph, assembly constraints, and full-model assembly metadata.
- `api/GeometryRef.md` — `GeometryRef(kind: str, source_node_id: Optional[str], geo_selector: Dict[str, Any], flip: bool = False)` serializes a QL-selected Face, Edge, or Vertex fingerprint for later re-resolution, negating the derived placement Z axis when `flip=True`.
- `api/GraphSession.md` — `GraphSession(graph_id: Optional[str] = None)` is a context manager that records CAD operations into a DAG exposed through the session after recording.
- `api/Material.md` — `Material(material_id: str, name: Optional[str] = None, density: Optional[float] = None, density_unit: Optional[str] = None, color: Optional[Vec3] = None)` defines material data assigned to a `Part` through `assign_material_rpart`.
- `api/Part.md` — `Part(part_id: str, body: Solid, name: Optional[str] = None, material: Optional[Material] = None, connectors: Tuple[Connector, ...] = ())` wraps exactly one `Solid` as a single-body product item.
- `api/Placement.md` — `Placement(origin: Vec3, x_axis: Vec3 = (1.0, 0.0, 0.0), y_axis: Vec3 = (0.0, 1.0, 0.0), z_axis: Vec3 = (0.0, 0.0, 1.0))` is a right-handed mapping from child-local to parent coordinates.
- `api/ScalarLimit.md` — `ScalarLimit(lower_value: float, upper_value: float)` defines a closed scalar range for a constraint drive coordinate.
- `api/SemanticDelta.md` — `SemanticDelta(created: Tuple[SemanticRef, ...] = (), modified: Tuple[SemanticRef, ...] = (), deleted: Tuple[SemanticRef, ...] = (), metadata: Dict[str, Any] = field(default_factory=dict))` records semantic entities created, modified, or deleted by one operation.
- `api/SemanticRef.md` — `SemanticRef(graph_id: str, node_id: str, entity_type: str, entity_id: str)` is a stable reference to a semantic model entity in a recorded graph.
- `api/SimpleCADError.md` — `SimpleCADError(operation: str, guidance: ErrorGuidance)` is a structured `ValueError` variant carrying LLM-oriented repair guidance.
- `api/Sketch.md` — `Sketch(curves: Iterable[Edge | Wire] | None = None, *, name: Optional[str] = None, plane: Any = 'XY', sketch_id: Optional[str] = None)` is a declarative constrained-sketch container that should be built through functional sketch APIs, while `curves` remains only for reading already-built edge or wire containers.
- `api/SketchConstraint.md` — `SketchConstraint(constraint_id: str, kind: str, targets: Tuple[Dict[str, Any], ...], value: Any = None, driving: bool = True, metadata: Dict[str, Any] = field(default_factory=dict))` serializes a constraint inside a declarative sketch.
- `api/SketchConstraintDiagnostic.md` — `SketchConstraintDiagnostic(constraint_id: Optional[str], severity: str, code: str, message: str, residual: Optional[float] = None)` represents a diagnostic emitted by the sketch solver.
- `api/SketchRef.md` — `SketchRef(sketch_id: str, entity_id: str, *, kind: str, subentity: str = 'geometry')` is a stable reference to a sketch entity or subentity.
- `api/SketchSolveResult.md` — `SketchSolveResult(sketch_id: str, status: str, dof: int, residual_norm: float, iterations: int, solved_points: Dict[str, Tuple[float, float]], solved_scalars: Dict[str, float], diagnostics: Tuple[SketchConstraintDiagnostic, ...] = ())` reports the result of solving a declarative sketch.
- `api/Var.md` — `Var(name: str, default: float, comment: str | None = None, expr_id: str = field(default_factory=lambda : _make_expr_id('var')))` is a named scalar parameter with a default fallback value.
- `api/add_arc_rsketch.md` — `add_arc_rsketch(sketch: Sketch, entity_id: str, start: Union[SketchRef, str], end: Union[SketchRef, str], center: Union[SketchRef, str], *, construction: bool = False) -> Sketch` returns an updated sketch containing the arc entity.
- `api/add_belt_constraint_rassembly.md` — `add_belt_constraint_rassembly(assembly: Assembly, constraint_id: str, connector_a: ConnectorRef, connector_b: ConnectorRef, pulley_radius_a: float, pulley_radius_b: float, phase_offset: Optional[float] = None, name: Optional[str] = None) -> Assembly` couples two revolute axes as same-direction belt-linked pulleys.
- `api/add_bspline_rsketch.md` — `add_bspline_rsketch(sketch: Sketch, entity_id: str, start: Union[SketchRef, str], end: Union[SketchRef, str], control_points: Sequence[Sequence[float]], degree: int = 3, knots: Optional[Sequence[float]] = None, multiplicities: Optional[Sequence[int]] = None, weights: Optional[Sequence[float]] = None, periodic: bool = False, *, construction: bool = False) -> Sketch` adds a B-spline whose start and end refs link it into a profile loop while its control points are stored as literal 2D coordinates.
- `api/add_circle_rsketch.md` — `add_circle_rsketch(sketch: Sketch, entity_id: str, center: Union[SketchRef, str], radius: ScalarLike, *, construction: bool = False) -> Sketch` returns an updated sketch containing a named circle.
- `api/add_component_rassembly.md` — `add_component_rassembly(assembly: Assembly, item: Union[Part, Assembly], component_id: str, placement: Placement, name: Optional[str] = None) -> Assembly` adds a placed `Part` or subassembly component instance.
- `api/add_connector_rassembly.md` — `add_connector_rassembly(assembly: Assembly, connector: Connector) -> Assembly` attaches a connector datum frame to an `Assembly`.
- `api/add_connector_rpart.md` — `add_connector_rpart(part: Part, connector: Connector) -> Part` attaches a connector datum frame to a `Part`.
- `api/add_fixed_constraint_rassembly.md` — `add_fixed_constraint_rassembly(assembly: Assembly, constraint_id: str, connector_a: ConnectorRef, connector_b: ConnectorRef, name: Optional[str] = None) -> Assembly` constrains two component connectors to the same frame.
- `api/add_gear_constraint_rassembly.md` — `add_gear_constraint_rassembly(assembly: Assembly, constraint_id: str, connector_a: ConnectorRef, connector_b: ConnectorRef, pitch_radius_a: float, pitch_radius_b: float, phase_offset: Optional[float] = None, name: Optional[str] = None) -> Assembly` couples two revolute axes as inverse-rotating meshing gears.
- `api/add_line_rsketch.md` — `add_line_rsketch(sketch: Sketch, entity_id: str, start: Union[SketchRef, str], end: Union[SketchRef, str], *, construction: bool = False) -> Sketch` returns an updated sketch containing a named line.
- `api/add_point_rsketch.md` — `add_point_rsketch(sketch: Sketch, point_id: str, x: ScalarLike, y: ScalarLike) -> Sketch` returns an updated sketch containing a named point.
- `api/add_prismatic_constraint_rassembly.md` — `add_prismatic_constraint_rassembly(assembly: Assembly, constraint_id: str, connector_a: ConnectorRef, connector_b: ConnectorRef, drive_distance: Optional[float] = None, distance_limit: Optional[ScalarLimit] = None, name: Optional[str] = None) -> Assembly` constrains two connectors as a prismatic slider pair with an optional drive distance or closed limit.
- `api/add_rack_pinion_constraint_rassembly.md` — `add_rack_pinion_constraint_rassembly(assembly: Assembly, constraint_id: str, rack_connector: ConnectorRef, pinion_connector: ConnectorRef, pitch_radius: float, phase_offset: Optional[float] = None, name: Optional[str] = None) -> Assembly` couples a prismatic rack axis to a revolute pinion axis.
- `api/add_revolute_constraint_rassembly.md` — `add_revolute_constraint_rassembly(assembly: Assembly, constraint_id: str, connector_a: ConnectorRef, connector_b: ConnectorRef, drive_angle_degrees: Optional[float] = None, angle_limit: Optional[ScalarLimit] = None, name: Optional[str] = None) -> Assembly` constrains two connectors as a revolute axis pair with an optional drive angle or closed limit.
- `api/and_.md` — `and_(*predicates: Predicate) -> Predicate` combines predicates so every predicate must match.
- `api/apply_tag.md` — `apply_tag(shape: AnyShape, tag: str) -> AnyShape` applies an already-normalized lowercase tag under the fixed policy that propagates semantic role, anchor, and group tags downward but keeps topology-specific tags local.
- `api/assign_material_rpart.md` — `assign_material_rpart(part: Part, material: Material) -> Part` returns the `Part` updated with the given `Material`.
- `api/chamfer_rsolid.md` — `chamfer_rsolid(solid: Solid, edges: Union[Sequence[Edge], ShapeSelector], distance: ScalarLike) -> Solid` applies a chamfer of the given distance to selected solid edges.
- `api/const_function.md` — `const(value: int | float) -> Const` creates a constant scalar node for parameterized modeling.
- `api/constrain_angle_rsketch.md` — `constrain_angle_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], value: ScalarLike, *, constraint_id: Optional[str] = None, driving: bool = True) -> Sketch` adds an angle constraint between two sketch lines.
- `api/constrain_coincident_rsketch.md` — `constrain_coincident_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` constrains two sketch points to coincide.
- `api/constrain_collinear_rsketch.md` — `constrain_collinear_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` constrains two sketch lines to the same infinite line.
- `api/constrain_concentric_rsketch.md` — `constrain_concentric_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` constrains two sketch circles to share a center.
- `api/constrain_connect_rsketch.md` — `constrain_connect_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` is a connection-worded alias of `constrain_coincident_rsketch`.
- `api/constrain_diameter_rsketch.md` — `constrain_diameter_rsketch(sketch: Sketch, circle: Union[SketchRef, str], value: ScalarLike, *, constraint_id: Optional[str] = None, driving: bool = True) -> Sketch` adds a circle diameter constraint.
- `api/constrain_distance_rsketch.md` — `constrain_distance_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], value: ScalarLike, *, constraint_id: Optional[str] = None, driving: bool = True) -> Sketch` adds a point-to-point distance constraint.
- `api/constrain_distance_x_rsketch.md` — `constrain_distance_x_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], value: ScalarLike, *, constraint_id: Optional[str] = None, driving: bool = True) -> Sketch` adds a horizontal distance constraint.
- `api/constrain_distance_y_rsketch.md` — `constrain_distance_y_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], value: ScalarLike, *, constraint_id: Optional[str] = None, driving: bool = True) -> Sketch` adds a vertical distance constraint.
- `api/constrain_equal_length_rsketch.md` — `constrain_equal_length_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` constrains two sketch lines to equal length.
- `api/constrain_equal_radius_rsketch.md` — `constrain_equal_radius_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` constrains two sketch circles to equal radius.
- `api/constrain_fix_rsketch.md` — `constrain_fix_rsketch(sketch: Sketch, target: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` fixes a sketch point or entity at its initial coordinates.
- `api/constrain_horizontal_rsketch.md` — `constrain_horizontal_rsketch(sketch: Sketch, line: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` constrains a sketch line to be horizontal.
- `api/constrain_length_rsketch.md` — `constrain_length_rsketch(sketch: Sketch, line: Union[SketchRef, str], value: ScalarLike, *, constraint_id: Optional[str] = None, driving: bool = True) -> Sketch` adds a line length constraint.
- `api/constrain_midpoint_rsketch.md` — `constrain_midpoint_rsketch(sketch: Sketch, point: Union[SketchRef, str], line: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` constrains a sketch point to a line's midpoint.
- `api/constrain_parallel_rsketch.md` — `constrain_parallel_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` constrains two sketch lines to be parallel.
- `api/constrain_perpendicular_rsketch.md` — `constrain_perpendicular_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` constrains two sketch lines to be perpendicular.
- `api/constrain_point_on_rsketch.md` — `constrain_point_on_rsketch(sketch: Sketch, point: Union[SketchRef, str], entity: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` constrains a sketch point to lie on a line or circle.
- `api/constrain_radius_rsketch.md` — `constrain_radius_rsketch(sketch: Sketch, circle: Union[SketchRef, str], value: ScalarLike, *, constraint_id: Optional[str] = None, driving: bool = True) -> Sketch` adds a circle radius constraint.
- `api/constrain_symmetric_rsketch.md` — `constrain_symmetric_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], axis: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` constrains two sketch points to be symmetric about a line axis.
- `api/constrain_tangent_rsketch.md` — `constrain_tangent_rsketch(sketch: Sketch, a: Union[SketchRef, str], b: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` constrains supported sketch curves to be tangent.
- `api/constrain_vertical_rsketch.md` — `constrain_vertical_rsketch(sketch: Sketch, line: Union[SketchRef, str], *, constraint_id: Optional[str] = None) -> Sketch` constrains a sketch line to be vertical.
- `api/cut_rsolid.md` — `cut_rsolid(*solids: Union[Solid, Sequence[Solid]], skip_non_intersecting: bool = True) -> Solid` flattens nested inputs, subtracts each tool from the first solid in order, and by default ignores tools without meaningful intersection while strict diagnostic replay should pass `False`.
- `api/export_graph_json.md` — `export_graph_json(graph: OperationGraph, indent: int = 2) -> str` serializes an operation graph to a JSON string using the requested indentation.
- `api/export_model_json.md` — `export_model_json(session: 'GraphSession', indent: int = 2) -> str` exports canonical 2.0 model seed JSON containing the session's operation graph, expression graph, capabilities, and schema metadata.
- `api/export_session_json.md` — `export_session_json(session: 'GraphSession', indent: int = 2) -> str` exports a graph session and its expression graph as JSON.
- `api/export_step.md` — `export_step(shapes: Union[AnyShape, Sequence[AnyShape]], filename: str) -> None` flattens a single shape or nested shape collection, including pattern `List[Solid]` results, into one STEP file.
- `api/export_stl.md` — `export_stl(shapes: Union[AnyShape, Sequence[AnyShape]], filename: str) -> None` writes a single compound, solid, or face or any nested sequence of them, including pattern `List[Solid]` results, into one STL file.
- `api/extrude_rsolid.md` — `extrude_rsolid(profile: Union[Wire, Face], direction: Tuple[float, float, float], distance: ScalarLike) -> Solid` creates a solid by extruding a wire or face profile along a direction.
- `api/fillet_rsolid.md` — `fillet_rsolid(solid: Solid, edges: Union[Sequence[Edge], ShapeSelector], radius: ScalarLike) -> Solid` applies the given fillet radius to selected solid edges.
- `api/fit_cubic_bspline_control_points.md` — `fit_cubic_bspline_control_points(sample_points: Sequence[Sequence[float]], *, tolerance: float = 0.001, max_control_points: Optional[int] = None, fairing: float = 1e-06, duplicate_tolerance: float = 1e-12, knot_tolerance: float = 1e-09, raise_on_failure: bool = True) -> BSplineFitResult` fits a C2 cubic clamped B-spline to cleaned ordered 2D or 3D samples using chord-length least squares, fairing, and adaptive simple knots, returning the best non-converged result only when `raise_on_failure=False` and otherwise raising `ValueError` for invalid input or unmet tolerance.
- `api/forward_connector_rassembly.md` — `forward_connector_rassembly(assembly: Assembly, connector_id: str, source_component_id: str, source_connector_id: str, name: Optional[str] = None, offset: Optional[Placement] = None) -> Assembly` exposes an internal component connector at assembly level by composing component placement, source connector placement, and optional offset.
- `api/geo.md` — `geo(field: str, default: Any = None) -> SerializableKey` creates a shortcut key for reading `geom.*` fields in QL queries.
- `api/get_sketch_entity_rsketchref.md` — `get_sketch_entity_rsketchref(sketch: Sketch, entity_id: str) -> SketchRef` returns a stable reference to a named sketch entity.
- `api/get_sketch_point_rsketchref.md` — `get_sketch_point_rsketchref(sketch: Sketch, point_path: str) -> SketchRef` returns a stable reference to a sketch point or endpoint path.
- `api/ground_component_rassembly.md` — `ground_component_rassembly(assembly: Assembly, component_id: str) -> Assembly` grounds a component at its current authored placement.
- `api/helical_sweep_rsolid.md` — `helical_sweep_rsolid(profile: Wire, pitch: float, height: float, radius: float, center: Tuple[float, float, float] = (0, 0, 0), dir: Tuple[float, float, float] = (0, 0, 1)) -> Solid` sweeps a wire profile along a helix to create a solid.
- `api/identity_placement_rplacement.md` — `identity_placement_rplacement() -> Placement` creates an identity placement.
- `api/import_graph_json.md` — `import_graph_json(json_str: str) -> OperationGraph` parses a JSON string into a reconstructed operation graph.
- `api/import_model_json.md` — `import_model_json(json_str: str) -> Dict[str, Any]` imports canonical 2.0 model seed JSON.
- `api/import_session_json.md` — `import_session_json(json_str: str) -> Dict[str, Any]` imports a session payload containing an operation graph and expression graph.
- `api/inspect_assembly_constraints_rconstraintreport.md` — `inspect_assembly_constraints_rconstraintreport(assembly: Assembly) -> ConstraintReport` returns all assembly constraint residuals without mutating the assembly.
- `api/inspect_sketch_rsketchresult.md` — `inspect_sketch_rsketchresult(sketch: Sketch, *, require_fully_constrained: bool = False, strict: bool = True, tolerance: float = 1e-07, max_iterations: int = 80) -> SketchSolveResult` runs the sketch solver for inspection without recording graph nodes.
- `api/intersect_rsolid.md` — `intersect_rsolid(*solids: Union[Solid, Sequence[Solid]]) -> Solid` flattens one or more nested solid inputs and returns their single overlap solid, raising a clear error rather than returning an empty list when no meaningful overlap exists.

- `api/make_2d_union_rface.md` — `make_2d_union_rface(face_a: Face, face_b: Face) -> Face` merges two 2D faces into one connected face and therefore requires them to overlap or touch.

## Architecture
- `architecture/sdk-architecture-review.md` — SimpleCADAPI is an OCP-native SDK with a strong functional `make_*_r*` API and graph/JSON replay direction, but its reliable-CAD boundary is undermined by global effect state, hidden mutable metadata, unstable OCC-based topology identity, incomplete canonical selection and schema contracts, permissive and context-insensitive replay, unfaithful boolean tracking, immature removed assembly/SDF surfaces, and insufficient robustness tests, so the review prioritizes strict fail-fast replay, context isolation, QL-first `SelectionSpec`, canonical operation/schema unification, and stronger topology, tagging, and test contracts over more primitives.

## Core
- `core/compound.md` — Compound is an explicit flattened multi-shape projection wrapper for assembly geometry, while normal part modeling remains centered on a single Solid and product structure must remain in Assembly.
- `core/coordinate_system.md` — CoordinateSystem stores a right-handed orthonormal local frame with an origin and axes, transforms local points and vectors into global coordinates, and provides readable diagnostics.
- `core/declarative_constraints.md` — Declarative sketch construction is functional and ID-based, promotes solved Sketch values to Wire or Face with recorded solve evidence while diagnostics remain non-recording, translates promotions to visible `Sketcher::SketchObject` objects while recording rejected FreeCAD constraints as skipped, and temporarily removes assembly containers, explicit part transforms, and assembly constraints pending a new graph contract.
- `core/edge.md` — Edge wraps a valid OCP one-dimensional curve with tags and metadata, exposes length and endpoint vertices, supports line, circle, arc, and exact B-spline forms, and requires attention to direction, closure, approximation, and floating-point geometry.
- `core/face.md` — Face wraps a valid OCP bounded surface with tags and metadata, exposes area, parameterized normals, and its outer wire, and requires closed oriented boundaries with special handling for holes, degeneracy, and self-intersection.
- `core/operation_graph_json_spec.md` — This specification defines the versioned graph and model JSON interchange contracts, canonical low-level operation nodes, expression and frame graphs, semantic and topology deltas, normalized tags, selection resolution order, strict replay behavior, supported operation payloads, and current assembly and scalar-field limitations.
- `core/part_assembly_development_plan.md` — This plan defines the implemented single-Solid Part, Material, right-handed Placement, component-based Assembly, explicit Compound projection, serialization, replay, validation, and FreeCAD product-tree MVP while excluding multi-body parts, public features or bodies, physical properties, connectors, and mate solving.
- `core/rearchitecture_2_0.md` — This architecture freezes a shape-first functional redesign around OCP-native geometry values, separate expression and canonical operation graphs, explicit frames, sketches, dual semantic and topology history, stable replayable model JSON, and phased assembly reintegration without breaking public type and naming conventions.
- `core/rearchitecture_2_0_requirements.md` — This requirements document turns the 2.0 architecture into testable API-continuity, expression, geometry, OCP-kernel, operation, history, assembly, serialization, canonical-lowering, selection, replay, and staged acceptance criteria while excluding units, general symbolic algebra, complete sketch solving, and universal native CAD export.
- `core/serialization/expressions-and-replay.md` — Expression-backed parameters serialize evaluated JSON snapshots in `params` and expression references in `param_exprs` plus the top-level expression graph, while current deterministic replay uses canonical graph snapshots and ordered `leaf_ids` without re-evaluating changed variables, cannot serialize Python callables, and intentionally treats some selector data, topology references, and counts as ordinary JSON rather than scalar expressions.
- `core/serialization/features-booleans-transforms.md` — This guide specifies replay payloads for extrude, revolve, loft, sweep, transforms, booleans, and detail features, requires connected single-Solid union results and fixed selector fallback order, and lowers helical sweeps and linear or radial patterns into canonical primitive and transform nodes.
- `core/serialization/primitives-and-profiles.md` — This guide defines canonical replay serialization for points, curves, exact B-splines, helices, wires, faces, and primitive solids, with geometry recovered through ordered inputs and convenience wire, face, box, cylinder, sphere, cone, segment, and polyline APIs lowered into basic curve, profile, extrude, or revolve nodes.
- `core/serialization/scalar-fields.md` — Scalar-field and SDF modeling, public field APIs, canonical graph operations, generated API documentation, and model replay are unsupported until a new contract is designed, including for historical field-tree payloads.
- `core/shell.md` — Shell is not a stable public wrapper, so bounded surfaces use Face, closed bodies use Solid, and thin-walled geometry is created through shell_rsolid with removed faces and thickness.
- `core/simple_workplane.md` — SimpleWorkplane temporarily pushes a local coordinate frame for nested shape-first modeling and restores the previous frame on context exit.
- `core/solid.md` — Solid wraps valid closed OCP three-dimensional geometry with tags, metadata, and face tagging, exposes volume and complete face or edge lists, records explicit indexed face or edge picks as graph geo-select nodes, and supports boolean and detail features whose success and topology depend on geometric validity and regularity.
- `core/tagged_mixin.md` — TaggedMixin internally stores tags, metadata, and runtime data for topology wrappers, while public functional tagging normalizes and deterministically lists semantic tokens, applies controlled downward propagation, keeps topology-specific tags local, and reserves structured measurements and geometry facts for metadata.
- `core/vertex.md` — Vertex wraps a valid OCP point with mutable tags and metadata but read-only three-dimensional coordinates, and coordinate changes require creating a replacement vertex while comparisons should use floating-point tolerances.
- `core/wire.md` — Wire wraps a tagged OCP path of connected edges, exposes constituent edges and closure state for profiles and sweep paths, and requires endpoint continuity, closure and orientation discipline, with length equal to summed edge lengths and self-intersections needing special handling.
